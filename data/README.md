# Data Sources

Synthetic source-style data for data conversion reconciliation and lineage analytics.

- `entities.csv`: 36 conversion mapping records.
- `daily_metrics.csv`: 5,040 conversion mapping-day metric rows.
- `source_events.csv`: 760 operational events, QA checks, experiments, and stakeholder asks.
- `recommended_actions.csv`: 220 candidate actions with effort and expected lift.
