# Data Folder

This folder contains synthetic conversion verification data generated by `scripts/score_operating_data.py`.

## Files

- `mapping_register.csv`: field-level source-to-target mapping rows with business domain, source table, target object, transformation rule, lineage path, owner, workbook tab, and sign-off status.
- `reconciliation_results.csv`: batch-level load-ready to destination checks by mapping.
- `data_quality_findings.csv`: SQL audit findings with severity, issue type, root cause, business impact, owner, status, and aging.
- `incident_triage.csv`: verification-phase incident digest for stakeholder status reporting.

## Synthesis Notes

The generator uses a fixed random seed for reproducibility. The structure is modeled on enterprise migration programs where analysts maintain STTM workbooks, reconcile load-ready extracts to destination tables, and triage defects during SIT, UAT, mock cutover, and sign-off review.

The data is synthetic and does not represent any real company, client, system, migration, or production performance.
